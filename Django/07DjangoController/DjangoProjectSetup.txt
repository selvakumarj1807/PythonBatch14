Django Project Setup Guide
==========================

Prerequisites:
--------------
- Python installed (preferably 3.8+)
- pip installed (Python package manager)

Step-by-Step Instructions:
--------------------------

1. Check Python & pip Versions:
   --------------------------------
   python --version
   pip --version

2. Create a Virtual Environment:
   --------------------------------
   python -m venv myworld

3. Activate the Virtual Environment:
   ----------------------------------
   On Windows:
       .\myworld\Scripts\activate

   On macOS/Linux:
       source myworld/bin/activate


If have a CMD Error :

Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

4. Install Django:
   -----------------
   pip install django

   To verify:
   django-admin --version

5. Create a Django Project (in current directory):
   ------------------------------------------------
   django-admin startproject projectName .

6. Create a Django App:
   ---------------------
   python manage.py startapp app

7. Register the App in settings.py:
   ---------------------------------
   In projectName/settings.py, add your app to INSTALLED_APPS:

       INSTALLED_APPS = [
           ...
           'app',
       ]

8. app/templates/index.html

<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>

<body>
    <h1>Welcome Django Template or Controller!...</h1>

    {{ user_data }}

    <br><br>
    {{ view_data }}

    <hr>

    <table border="1" cellpadding="10" cellspacing="5">
        <tr>
            <th>Name</th>
            <th>Age</th>
            <th>Vote Eligible</th>
        </tr>
        {% for user in view_data %}
        <tr>
            <td>{{ user.name }}</td>
            <td>{{ user.age }}</td>
            <td>
                {% if user.age >= 18 %}
                    Eligible
                {% else %}
                    Not Eligible
                {% endif %}
            </td>
        </tr>
        {% endfor %}
    </table>
</body>

</html>

9. app/views.py

from django.shortcuts import render

# Create your views here.

def index(request):
    users = [101, 'Ram', 'Male', 25, 'Chennai']
    view_users = [
        {"name": 'Ram', "age": 25},
        {"name": 'Shyam', "age": 15},
        {"name": 'Sita', "age": 28},
        {"name": 'Gita', "age": 12},
    ]
    return render(request, 'index.html', {'user_data': users, 'view_data': view_users})

10. projectName/urls.py

from app import views

urlpatterns = [
    ....
    path('', views.index)
]


11. Run the Development Server:
   ----------------------------
   python manage.py runserver

   Open your browser at: http://127.0.0.1:8000

Your Django project is now set up and ready!
